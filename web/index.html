Help & advanced controls
  • Select reviews a point. Move enables dragging points and A/B.
  • Changing A–B changes all drawing distances. Undo restores the previous scale.
  • Sketch points adds approximate locations by tapping the plan.
  • Drag the background to pan. Pinch or use +/− to zoom.
  • Arrow keys nudge a selected point in Move mode. Escape returns to Select.
  • For exact offsets, open Points → Advanced coordinate table.
