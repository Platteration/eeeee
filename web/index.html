How it works

  • Click empty canvas to add a point; click a point to select it, drag to move it.
  • No mouse? Add point drops one in the middle of the view, ready to be typed into place.
  • Or type: the Along and Perp. cells are editable, so a distance off a tape measure places a point exactly.
  • Drag the green A and red B handles to set the baseline.
  • The declared A–B distance scales everything else — every measurement follows from it.
  • Drag with the background, middle button or Shift to pan; scroll to zoom.
  • ←↑→↓ nudge the selection (Shift for a bigger step), Delete removes it, Esc deselects.
